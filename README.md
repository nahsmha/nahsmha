# نحسمها — قاعدة بيانات موسعة

- 79 شركة و579 موديلًا.
- كل موديل يحتوي حقول المواصفات المطلوبة.
- البيانات المتوفرة حتى لو كانت غير موثقة تُعرض، مع وسم واضح: **غير موثق بالكامل**.
- لا تُعامل البيانات غير الموثقة كمرجع رسمي.
- الخانات التي لا تتوفر لها قيمة تبقى: **غير متوفر — غير موثق بالكامل**.
- سعة الشنطة غير مدرجة حسب مواصفات المشروع.
- اسم المطور: يحيى.
