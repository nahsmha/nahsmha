# نحسمها — قاعدة البيانات الموثقة

هذه النسخة تستخدم نظام بيانات مفصول عن منطق المقارنة.

## قاعدة البيانات
كل سجل سيارة مرتبط بـ:
- الشركة
- الموديل
- سنة الموديل
- الفئة
- السعر
- سعة المحرك
- عدد الأسطوانات
- القوة
- العزم
- استهلاك الوقود
- ناقل الحركة
- نظام الدفع
- نوع الوقود
- سعة خزان الوقود
- الأبعاد
- التسارع 0–100 عند توفر مصدر موثوق
- بيانات الأمان عند توفر مصدر موثوق
- المصدر

## قاعدة مهمة
لا يتم اختراع أو تقدير أي رقم. إذا لم توجد معلومة موثقة تظهر `غير متوفر`.

## المصادر
تم اعتماد صفحات الوكلاء الرسمية وبيانات كفاءة الوقود الرسمية في السعودية كأساس للمشروع. يتم توسيع قاعدة البيانات تدريجيًا مع التحقق من كل سنة وفئة.
