# نحسمها — GitHub Pages

هذه النسخة جاهزة للرفع إلى مستودع GitHub Pages.

## الطريقة
1. افتح مستودع `nahsmha`.
2. استبدل ملف `index.html` الحالي بهذا الملف.
3. Commit changes.
4. تأكد أن GitHub Pages يعمل من الفرع والمجلد الذي تستخدمه حاليًا.
5. افتح رابط موقعك من Safari على الآيفون.

> البيانات الحالية Demo للواجهة والمنطق. قبل النشر النهائي العام، يجب توثيق قاعدة السيارات والسنوات والمواصفات.
