# نحسمها — النسخة الكاملة
- 79 شركة
- 579 موديل
- جميع حقول المقارنة الأساسية مملوءة قدر الإمكان.
- البيانات المؤكدة تبقى كما هي.
- البيانات التقديرية موسومة بوضوح: «غير موثوق».
- البيانات التقديرية تدخل في المقارنة والنسب، ولا تُعرض كحقائق رسمية.
- إذا لم تكن المعلومة منطبقة (مثل الأسطوانات في السيارات الكهربائية) يظهر وصف مناسب.
- سعة الشنطة غير مدرجة.
- اسم المطور: يحيى.

ملاحظة: الأرقام التقديرية وضعت لتقليل الفراغات في قاعدة البيانات، وليست بديلًا عن مواصفات الوكيل أو الشركة المصنعة.
